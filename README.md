## Projects

**SmartSeason**
A web app for monitoring farm fields. Admins and field agents get their own dashboards, and the app tracks field updates and shows reports.

It has an AI assistant that uses tool calling. Users can ask things like "which fields have had no update for two weeks?" and the assistant looks up the real data through a set of safe tools. The AI never touches the database directly. Each tool follows the user's role, so agents only see their own fields. Actions that change data, like reporting an issue or assigning a field, only run after the user confirms.

Built with React, TypeScript, Django REST Framework, PostgreSQL and an AI API.
[View code](https://github.com/MillicentChelangat/SmartSeason-Field-Monitoring-System)
